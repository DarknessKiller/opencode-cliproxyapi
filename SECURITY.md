# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through a public issue.

Use the repository's
[private vulnerability reporting](https://github.com/yourcasualdev/opencode-cliproxyapi/security/advisories/new)
page instead.

Include reproduction steps, affected versions, and the expected security
impact. You should receive an acknowledgement within seven days.

## Credential handling

The plugin supports `CLIPROXY_API_KEY` so credentials do not need to be stored
in project configuration. Never commit CLIProxyAPI keys to a repository.
